# Rewards NFC Display 2.11.0

- Redesigns the kiosk display flow so rewards profile scanning is always open on the main rewards display.
- Adds an embedded front-camera scanner panel; staff no longer need to tap Scan Rewards Profile.
- Scanner posts Lightning-address QR check-ins directly to BTCPay and shows visual confirmation for the waiting customer.
- Includes a camera flip control and keeps the scanner compact when a reward QR is already being displayed.
- Keeps the screen-lock/network recovery from 2.10.1.
